First release of the core: `createHeadpress()` with the request transport (publishable key, Cart-Token, customer sessions with a shared refresh, captcha, module checks, timeouts), the store config with ETag revalidation and stale fallback, capabilities, the route map (`expandRoute`, `matchRoute`), typed errors with `pt-BR`, `en` and `es` texts, `Money`, plugins, and the `/server` entry (secret key, forwarded shopper IP, `clientIp()`). Requires Headpress 1.2 or later.
